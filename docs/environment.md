# Environment Variables

Single source: `.env.example`. `make init` creates `.env` from it (merges, never overwrites existing keys).

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `TIMEWEB_API_KEY` | ✅ | – | AI provider chat key; model `apiKey` in `.pi/models.json` |
| `AI_API_URL` | ✅ | – | Memory embedding endpoint (OpenAI-compatible). Required by `pgvec-memory` startup |
| `AI_API_KEY` | ✅ | – | Memory embedding/auth key. Must be non-empty (`pgvec-memory` startup validation) |
| `AI_API_EMBEDDING_MODEL` | ✅ | – | Memory embedding model (persisted contract — changing requires a vector rebuild) |
| `AI_API_EMBEDDING_DIMENSIONS` | ✅ | – | Memory embedding vector dimensions (must match the model) |
| `IMAGE_API_URL` | – | – | Image generation fallback base URL (used by `openai-image-gen` `generate_image`; env override of `.pi/settings/pi-openai-image-generation.json`) |
| `IMAGE_API_KEY` | – | – | Image generation fallback key (`generate_image`) |
| `OPENAI_IMAGE_BASE_URL` | – | – | Image fallback base URL override (falls back to `IMAGE_API_URL`) |
| `OPENAI_IMAGE_API_KEY` | – | – | Image fallback key override (falls back to `IMAGE_API_KEY`) |
| `HF_TOKEN` | – | – | HuggingFace Inference API token — used by `hf_generate_image` (drawer primary; `extensions/huggingface-image-gen`) |
| `HF_IMAGE_PROVIDER` | – | `auto` | Image provider override (else `.pi/settings/pi-huggingface-image-gen.json`) |
| `HF_IMAGE_MODEL` | – | `black-forest-labs/FLUX.2-klein-9B:preferred` | Image model override |
| `TELEGRAM_BOT_TOKEN` | ✅ | – | Telegram bot token for the bridge |
| `TELEGRAM_CHAT_ID` | ✅ | – | Target chat ID for bridge messages |
| `TELEGRAM_MENTION` | – | bot username or `@pi` | Telegram group mention trigger (`pi-telegram-bridge`) |
| `POSTGRES_PASSWORD` | ⚠️ conditional | auto | Password for PostgreSQL user `densemem` (memory-db); auto-generated by `make init` if empty |
| `PGVEC_PORT` | – | `8090` | Host port mapped to `pgvec-memory` container port 8090 |
| `NODE_USE_ENV_PROXY` | – | `1` | Enables HTTP(S)/NO_PROXY support for Node 24 fetch/undici (outbound TG routing via CONNECT proxy) |
| `HTTP_PROXY` / `HTTPS_PROXY` | – | empty | CONNECT proxy for outbound traffic (e.g. gost on a free-tier Oracle VM). Leave empty for direct connection |
| `NO_PROXY` | – | `localhost,127.0.0.1,memory-db` | Hosts that bypass the proxy (internal compose hosts must stay on this list) |
| `GITHUB_TOKEN` | – | – | GitHub API token (git push auth, `gh api` lookups, releases and CI status) |
| `VERCEL_TOKEN` | – | – | Vercel API token (staging deploy) |
| `VERCEL_ORG_ID` | – | – | Vercel organization ID |
| `FTP_HOST` | – | – | Production FTP host |
| `FTP_USER` | – | – | FTP username |
| `FTP_PASS` | – | – | FTP password |
| `CONTEXT7_API_KEY` | – | – | Context7 library docs (works without key at IP-based rate limits) |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | – | `http://jaeger:4318` | OTLP/HTTP endpoint for trace + metric export |
| `OTEL_SERVICE_NAME` | – | `pi-agent` | Trace/service name for the Pi agent |
| `PI_OTEL_ENABLED` | – | `true` | Set `false` to disable `pi-otel-telemetry` |
| `JAEGER_UI_PORT` | – | `16686` | Host port for the Jaeger UI (loopback only) |
