# Environment Variables

Single source: `.env.example`. `make init` creates `.env` from it (merges, never overwrites existing keys); `make setup` bootstraps dense-mem and auto-fills the auto-marked variables.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `TIMEWEB_API_KEY` | ✅ | – | AI provider chat key; model `apiKey` in `.pi/models.json` |
| `AI_API_URL` | ✅ | – | dense-mem embedding/assessor endpoint (OpenAI-compatible). Required by dense-mem startup |
| `AI_API_KEY` | ✅ | – | dense-mem embedding/auth key. Must be non-empty (dense-mem startup validation) |
| `AI_API_EMBEDDING_MODEL` | ✅ | – | dense-mem embedding model (persisted contract — changing requires a vector rebuild) |
| `AI_API_EMBEDDING_DIMENSIONS` | ✅ | – | dense-mem embedding vector dimensions (must match the model) |
| `TELEGRAM_BOT_TOKEN` | ✅ | – | Telegram bot token for the bridge |
| `TELEGRAM_CHAT_ID` | ✅ | – | Target chat ID for bridge messages |
| `POSTGRES_PASSWORD` | ⚠️ conditional | auto | Password for PostgreSQL user `densemem` (memory-db + dense-mem); auto-generated by `make init` if empty |
| `CONTROL_PORTAL_TOKEN` | ⚠️ conditional | auto | dense-mem control portal token; auto-resolved by `memory-bootstrap.sh` if not set |
| `DENSE_MEM_API_KEY` | ⚠️ auto | auto | dense-mem API key; auto-filled in `.env` by `memory-bootstrap.sh` |
| `DENSE_MEM_PORT` | – | `8080` | Host port mapped to dense-mem container port 8080 (MCP/API) |
| `CONTROL_PORTAL_PORT` | – | `8090` | Host port mapped to dense-mem control portal (port 8090) |
| `TEAM_NAME` | – | `pi-coder` | dense-mem team name (bootstrap) |
| `CREDS_NAME` | – | `default` | dense-mem credential name (bootstrap) |
| `AI_VERIFIER_API_URL` | – | – | Claim verifier endpoint (OpenAI-compatible chat-completions). Leave empty to reuse `AI_API_URL` |
| `AI_VERIFIER_API_KEY` | – | – | Claim verifier auth key. Required if `AI_VERIFIER_API_URL` is set; must be non-empty |
| `AI_VERIFIER_MODEL` | ✅ | – | Claim verifier model. Validated at dense-mem startup; required |
| `AI_VERIFIER_TIMEOUT_SECONDS` | – | `300` | Claim verifier timeout, wired to dense-mem via compose |
| `NODE_USE_ENV_PROXY` | – | `1` | Enables HTTP(S)/NO_PROXY support for Node 24 fetch/undici (outbound TG routing via CONNECT proxy) |
| `HTTP_PROXY` / `HTTPS_PROXY` | – | empty | CONNECT proxy for outbound traffic (e.g. gost on a free-tier Oracle VM). Leave empty for direct connection |
| `NO_PROXY` | – | `localhost,127.0.0.1,dense-mem,memory-db` | Hosts that bypass the proxy (internal compose hosts must stay on this list) |
| `GITHUB_TOKEN` | – | – | GitHub API token (git push auth, `gh api` lookups, releases and CI status) |
| `VERCEL_TOKEN` | – | – | Vercel API token (staging deploy) |
| `VERCEL_ORG_ID` | – | – | Vercel organization ID |
| `FTP_HOST` | – | – | Production FTP host |
| `FTP_USER` | – | – | FTP username |
| `FTP_PASS` | – | – | FTP password |
| `CONTEXT7_API_KEY` | – | – | Context7 library docs (works without key at IP-based rate limits) |
